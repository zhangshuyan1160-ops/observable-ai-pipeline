新建动画处理任务

高级设置 · 超时、故障步骤与资源

风格化每 4 帧保存检查点。GPU 为单槽模拟资源。启用缓存时，命中步骤不执行故障注入；要观察故障请关闭缓存。超时预设不会自动修改执行时限。

验证真正的进程中断

将预填 32 帧、每批 4 秒、关闭缓存的参数。提交后，待风格化步骤保存检查点后，在项目目录运行：

.venv/bin/python scripts/dev.py interrupt gpu

本地启动器会对自己的两个 GPU Worker 发送 SIGKILL 并重启它们。约 10–15 秒后，新的执行尝试从检查点继续。右侧资源面板可看到新 Worker。

适用于 scripts/dev.py start 启动方式。界面不会提供任意进程终止接口。

取消这个任务？

后续步骤将停止领取，运行中的步骤会在安全边界停止。已完成的产物和执行历史会保留。取消后如需再运行，可以复制参数创建新任务。
