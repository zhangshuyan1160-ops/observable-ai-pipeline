### 实际遇到的错误与修正

1. GPU 测试辅助函数曾假设“执行两次 CPU claim 必然到达第二任务的 GPU 步骤”；失败时实际领取的是第一个任务的 thumbnail 分支。原因是全局队列会混合不同任务，改为按目标任务步骤状态条件推进。这是测试假设错误，不伪装成执行器故障。
2. UI 点击终态任务步骤时重建 DOM，把事件/资源容器清空，而终态详情不再重复请求。改为保存最近 events/resources 并在切换步骤后重绘，浏览器验证面板保留。
3. 表单模型版本 pattern 在 JS 模板字符串里有反斜杠转义风险；取消重复的 HTML 正则，保留后端 Pydantic 校验，实际提交 mock-v1 成功。
4. 依赖锁初次整理漏掉 FastAPI 新增的 opentelemetry-api 传递依赖，核对包元信息后补齐。仅依赖存在不代表实现了 OTel tracing。
5. GitHub HTTPS helper 没有已保存凭据；连接器没有创建仓库接口，GitHub 创建页多次读取超时。源码与压缩验证继续推进，请用户仅创建一个初始化的公开仓库；不索取密码/Token。
