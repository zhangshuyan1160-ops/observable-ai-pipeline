# 提交前质量收尾：PDF 建议评审与实施

基线：`f32cb6d`（v0.2）。本轮在 `codex/submission-quality` 分支修改，沿用 FastAPI / PostgreSQL / 独立 Worker / 原生前端。PDF 是建议材料，按源码和实际行为核对后采纳，不把其中的完成要求当成已经完成的事实。

## 采纳判断

| PDF 建议 | 判断与实施 |
| --- | --- |
| 创建意图使用稳定幂等键 | 必须修：原界面每次点击新建键，服务端幂等无法保护响应丢失后的重试。现在发送前持久化键和参数快照；重试、刷新后确认均使用原请求。 |
| 区分复制参数与结果复用 | 必须修：原按钮静默开启缓存、关闭故障。现在两个入口都打开可审查表单；复制完整保留配置，复用仅更改明确告知的两项。 |
| “每批耗时”含义不符 | 必须修：接入 batch_delay，普通步骤耗时放到高级设置；留空沿用 step_delay。支持 4–64 的任意整数帧数。 |
| 错误、预算、阻塞与恢复信息 | 采纳：展示实际 error_type、轮次/上限、next_run_at、阻塞祖先、恢复帧数、未重执行的成功上游。无预计完成时间或节省耗时猜测。 |
| 缓存来源与校验 | 采纳：通过 artifact → producing attempt → task 关联原始来源；展示指纹、SHA-256 和命中事件时间。说明这是历史校验，下载时重新检查。 |
| 页面与代码整理 | 采纳：直接标题、三个演示入口、可展开错误/原始事件、字号及窄屏滚动提示；创建意图、表单、详情、DOM 更新分模块，视图按职责拆函数。 |
| 轮询保持焦点/展开状态 | 采纳：按任务/步骤/attempt/event 键更新现有 DOM；输入表单不在轮询区域。状态摘要增减时也保留尝试表格；资源/事件容器独立更新。 |
| 本人贡献、人工用时、AI 披露 | 采纳真实性约束：记录本人确定两天期限、本地执行和 v0.2 四项优先级；Codex 参与方案梳理、实现、验证与文档。个人工时未单独记录，无法确定最耗时项。 |
| 大规模重构、真实模型/多机能力 | 无新增必要：没有证据要求替换执行器；本轮不引入前端框架、Redis 或新生产依赖。 |
| 发布 | 用户已授权将质量收尾及后续连线修复作为 v0.3.0 同步至公开仓库，并更新源码 ZIP；远程校验另行记录，原本地证据保留。 |

## 创建协议与边界

- 使用当前标签页的 `sessionStorage`，存储发生在 POST 之前。保存失败则不发送请求，避免无法重试的写入。
- 请求发出后，表单锁定快照。关闭弹窗不取消服务端任务，首页保留“提交结果待确认”入口；刷新后可恢复。
- 超时、断网、5xx、无有效 task ID 的响应均保留原意图；得到有效 task ID 后才清除。409/422 也保留记录供检查，参数修正必须明确另建。
- “另建任务”明确提示旧请求可能已成功、可能产生第二个任务。确认后才清除原意图并允许编辑，新提交生成新键。不自动取消旧任务。
- 普通草稿尚未提交时不保存；标签页关闭、站点数据清除、切换浏览器/端口不在恢复保证内。不同标签页独立创建是不同意图；这不是跨设备草稿同步。
- 复制表单通过完整快照叠加展示字段，暂未展示字段不静默丢弃；未知字段仍由 API 严格校验。故障选择不会静默改缓存或时限，演示预设则明确预填配置。

## 验证记录

本轮新增 PostgreSQL/HTTP 测试覆盖前端意图模块 + 真实 API + 数据库单任务约束，以及跨多次缓存命中的原始生产者溯源。另有前端状态测试覆盖响应丢失/刷新、存储失败、畸形响应、明确另建和完整参数复制。

实际测试结果、浏览器任务 ID、截图和范围见 `evidence/quality-verification.json` 与 `evidence/tests-quality.xml`。本轮测试使用独立测试数据库；页面验证仅新增“质量验收”任务，未删除或改动原有任务及产物。

真实响应丢失的浏览器复现工具：

```bash
# 先启动正常本地服务；另一个终端运行：
.venv/bin/python scripts/response_loss_proxy.py
# 打开 http://127.0.0.1:8766，新建一个明确命名的验证任务。
# 代理在首次 POST 已收到 202 后切断响应；刷新页面，再确认原请求。
# 两次请求/响应记录在 .local/quality/response-loss.json；Ctrl+C 停止代理。
```

代理仅是显式运行的本地测试夹具，不加入正常启动流程，不提供终止 Worker 的网络接口。不要用它代理真实公网流量。

历史一小时证据仍为 v0.2 的 3607.93 秒演练；本次没有重跑，也不把历史 CI 通过算作本轮 CI。真实 GPU、生产鉴权、多机隔离、负载压测、Compose 启动和完整无障碍审计仍未验证。人工练习清单仍为待完成，不能归为本人已完成的开发经历。
