# 演示检查清单

这份清单用于复现和讲解项目。已完成的自动化验证见 [验收矩阵](failure-matrix.md)，演示流程见 [demo.md](demo.md)。

## 检查中断恢复

按 README 启动服务，新建 32 帧、每批 4 秒、关闭缓存的任务。风格化至少保存 4 帧后，在项目目录执行：

```bash
.venv/bin/python scripts/dev.py interrupt gpu
```

观察旧尝试变为 INTERRUPTED，新尝试从检查点继续；核对 probe、extract 没有新增尝试。记录任务 ID、旧/新 Worker、保存帧数和恢复起点。

讲解要点：为什么租约过期前不会立即重领，为什么旧 Worker 不能覆盖结果，最后一个未提交批次为何可能重算。

## 检查重试与结果复用

1. 创建“首次失败”任务，观察失败后自动重试。
2. 创建“本轮全部失败，手动恢复”任务，耗尽尝试后手动重试，核对旧历史和成功上游仍保留。
3. 正常完成启用缓存的任务，再验证结果复用，检查 CACHED 状态与产物来源。
4. 修改模型版本，观察风格化及下游重算，上游继续复用。

## 检查任务管理与交互

- 运行中取消任务，观察 CANCELLING 到 CANCELLED、资源释放和历史保留。
- 归档任务，再按名称和状态查回、恢复到列表。
- 复制参数，检查帧数、批次耗时、模型、故障配置和执行时限。
- 展开错误详情，等待页面轮询，确认内容保持展开。
- 在窄屏上横向滚动管线，点击节点查看明细。

## 讲解重点

- `engine.py` 中领取、续租、提交、回收和手动重试的事务边界。
- 请求幂等键与结果缓存指纹的区别。
- 任务、步骤与 attempt 分别记录什么，为什么历史不覆盖。
- 模拟 GPU 槽与真实 GPU 进程生命周期的区别。
- 从本地小文件扩展到大视频和小时级任务时，哪些部分需要改变。
